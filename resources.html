    Resources

    Checklists you can work through today, plus the official services and independent tools we recommend. None of these links are affiliate links, and nobody paid to be listed.

    Print or save

    Quick checklists

    The 30-minute account lockdown

    • Install a password manager and save your email password in it first
    • Turn on two-factor authentication for email, bank and Apple/Google account
    • Add a passkey wherever it is offered
    • Print or store your recovery codes offline
    • Check your email address on Have I Been Pwned
    Full guide

    Home network check

    • Change the router admin password
    • Update the router firmware
    • Use WPA3 or WPA2-AES Wi-Fi security
    • Turn off WPS and remote administration
    • Put smart devices on a guest network
    Full guide

    If you think you’ve been scammed

    • Stop all contact and payments
    • Call your bank using the number on your card
    • Change any password you disclosed, and sign out other sessions
    • Remove any remote-access software you were told to install
    • Report to ReportFraud.ftc.gov / IC3 (US) or Action Fraud (UK)
    Full guide
